# HUNG PHAT AI — UI/UX Prototype

## Cấu trúc
- `index.html`: cấu trúc giao diện và các màn hình.
- `styles.css`: thiết kế, hiệu ứng viền, ánh sáng, hover, responsive.
- `app.js`: điều hướng, chọn tệp demo, chạy mô phỏng pipeline, xuất HTML demo.

## Cách chạy
1. Giải nén thư mục.
2. Mở `index.html` bằng Chrome, Edge hoặc Firefox.
3. Không cần cài đặt package hay chạy server.

## Hiệu ứng giao diện
- Sidebar navy gradient.
- Hero banner với vòng sáng/orbit và nền công nghệ.
- Card có shadow, hover lift và viền sáng.
- Pipeline cards có trạng thái.
- Responsive cho desktop, tablet và mobile.

## Lưu ý
Đây là prototype front-end. Chức năng chọn tệp chỉ hiển thị tên/kích thước; pipeline là mô phỏng giao diện, chưa kết nối Lark Base, Google Sheets, Python backend hoặc mô hình AI. Các điểm số địa bàn là dữ liệu minh họa, không dùng làm kết luận kinh doanh.
